# Security policy

Report a suspected vulnerability by email to security@civico.de. Please do not
open a public issue for it. You can encrypt your report with our OpenPGP key:
https://civico.de/.well-known/pgp-key.asc
(fingerprint 6061 2D9A C28C CECF 4BDD 567A BD18 04A8 01CE 072D).

Include the affected repository and version and the steps to reproduce. Fixes
are released for the latest version only.
